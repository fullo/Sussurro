Proposal A (adapted) — Workspace with sidebar

Chosen proposal (P1), updated for the speech-to-text workbench re-scope (plan section 9). The app is a desktop workspace; hotkey dictation stays tray-first and is configured under Settings. Window ≈ 1120×740.

What changed versus the original proposal A

  • Rail is now New · Library · People · Recipes · Models · Settings. Meetings, Voices, Dictate and History are gone: every source starts from New, every result lands in Library as a note, meeting or transcription (P10), and the dictation history moves under Settings → Dictation.
  • The document pane gains tabs (Transcript · Document · Audio) and a metadata header with editable tags, categories and participant chips (name + email from the People registry, P5).
  • Speakers are only Meet names and generic Voice N labels (P8): no "known voice" matching and no voice map in the main view (optional card in 0.10). A voice can be renamed or linked to a person.
  • The context pane is Speakers · Ask · Export. Ask runs recipes on a chosen LLM profile, with external profiles visibly marked (P6); the Library marks items sent to an external LLM.
  • Engine and cleanup labels follow the current stack (Whisper / Ollama or any OpenAI-compatible server); no bundled-model claims. Audio is saved only on request (P9), subtitles per setting (P7).
