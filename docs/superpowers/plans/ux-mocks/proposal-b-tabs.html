Proposal B — Tabs on the existing page + a dedicated meeting window

Evolutionary: the current single-column settings page stays as it is, but gains a segmented control at the top — Dictation (today's page, unchanged), Meetings (archive list + extension pairing) and Models (engines). Opening a meeting spawns a separate window, like the overlay already is, so the editor can be wide without changing the main window (700×860). Live transcript, naming, editing, map and replay all happen in the meeting window; the extension side panel only shows the live text.
