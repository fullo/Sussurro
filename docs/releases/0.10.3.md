# Sussurro 0.10.3: recipes on thinking models

> **Update:** [0.11.0](0.11.0.md) adds suggest-only voice recognition,
> overlap-aware speaker labels, Teams/Zoom web names, Ogg Opus saved audio,
> an archive HTTP API, calendar attendees, and an experimental local
> read-aloud module.

A patch release on top of [0.10.2](0.10.2.md). It fixes recipes on local
LLMs served by Ollama. Nothing else changes. Update the app and the
extension together (their versions must match); the extension itself is
unchanged apart from its version number.

## Fixes

- **Recipes and questions work on "thinking" models.** With models that
  reason before answering (for example Qwen3 or Gemma 4 in Ollama), a long
  recipe such as *Meeting minutes* could fail with "the model returned an
  empty result": all of the output went into the model's reasoning. Sussurro
  now turns reasoning off in every request to Ollama, so the answer comes
  back directly. Dictation cleanup gets faster on these models too. (#318)
- **A small model that runs away is stopped.** A recipe step now has an
  output limit that matches the space the recipe already reserves for the
  answer, and lines that hold only a bullet (`*`, `-`) are removed. Before,
  a small model could fill a document with thousands of empty bullet
  lines. (#318)

The OpenAI-compatible path (LM Studio, llama.cpp server, the bundled model)
is unchanged.

## Upgrading

- Install the 0.10.3 app (or let the auto-updater do it) and the 0.10.3
  extension. Chrome, Edge and Brave: load the new unpacked zip. Firefox:
  the signed add-on updates itself, or install the `.xpi` from the release.
