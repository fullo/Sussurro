# Sussurro 0.10.2: settings and Windows fixes

> **Update:** [0.10.3](0.10.3.md) fixes recipes and questions on "thinking"
> models in Ollama, and caps a small model that runs away.

A patch release on top of [0.10.1](0.10.1.md). It fixes saving settings
when the dictation hotkey is taken, and the browser extension's live
connection on Windows. Nothing else changes. Update the app and the
extension together (their versions must match).

## Fixes

- **Settings are saved even when the hotkey is taken.** If another app
  held the dictation hotkey (for example a second copy of Sussurro), every
  change in Settings was silently lost, the archive folder included. Now
  the change is always saved. Choosing a *new* hotkey that another app
  already uses is refused with a clear message, and the previous hotkey
  keeps working. Before, you could be left with no hotkey at all. (#312)
- **Meetings from the browser survive long pauses on Windows.** The
  extension's live connection to the app could drop on Windows after 30
  seconds with nothing sent. It now stays open for the whole meeting, as on macOS
  and Linux. (#311)
- **A quieter local API.** A connection that opens the extension's live
  channel without logging in is now closed after 2 seconds, instead of
  being kept open indefinitely. (#311)

## Upgrading

- Install the 0.10.2 app (or let the auto-updater do it) and the 0.10.2
  extension. Chrome, Edge and Brave: load the new unpacked zip. Firefox:
  the signed add-on updates itself, or install the `.xpi` from the release.
