# Sussurro 0.10.1: meeting capture fixes

A patch release on top of [0.10.0](0.10.0.md). It changes only the browser
extension's meeting capture and the local API route the extension uses;
dictation, notes and the archive are the same as in 0.10.0. Update the app
and the extension together (their versions must match).

## Fixes

- **Microsoft Teams on its new address.** Microsoft is moving Teams for
  work and school accounts to `teams.cloud.microsoft` (from 30 September
  2026). The extension now recognizes and records meetings there, as well
  as on `teams.microsoft.com` and `teams.live.com`. (#291)
- **Zoom in the browser.** Zoom's web client runs the meeting inside an
  embedded frame; the extension now captures the call from that frame, so
  Zoom web meetings record again. (#291)
- **A language for each meeting.** The side panel has a *Language* menu
  next to Start: *Auto-detect* or one of the languages the app's current
  speech engine offers, listed by their own names. The choice applies to
  that meeting only (your dictation language in Settings doesn't change)
  and is remembered per platform. The app uses it for transcription, for
  the cleanup and as the meeting's `language`. An older app shows no menu.
  (#294)
- **Firefox 140 or later, desktop only.** The Firefox add-on now needs
  Firefox 140+ on desktop (Firefox for Android is not supported) and
  passes Mozilla's review checks without warnings. It is still signed by
  Mozilla and installed from the release's `.xpi`, and it updates itself.
  (#279)

## Upgrading

- Install the 0.10.1 app (or let the auto-updater do it) and the 0.10.1
  extension. Chrome, Edge and Brave: load the new unpacked zip. Firefox:
  the signed add-on updates itself, or install the `.xpi` from the release.
- Firefox older than 140 can't install the new add-on; update Firefox
  first.
