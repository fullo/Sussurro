The archive: notes, meetings and transcriptions

Hotkey dictation still pastes straight into your cursor. Everything longer — a voice note, an audio file, a link, a meeting — now becomes a plain markdown item in Documents/Sussurro that you own, search and edit.

6 min read · Feature guide

Sussurro 0.10 opens on a workspace with a left rail: New · Library · People · Recipes · Models · Settings. New is where every source starts, and the Library is where it ends up. There is no database you need Sussurro to read: each item is a folder of markdown files, and the search index is rebuilt from them whenever needed.

Three kinds of item

The type depends on what the audio is, not where it came from:

  • Note: your own voice dictating. It has no speakers and no participants.
  • Meeting: a live conversation among several people, from the browser extension, System audio + mic, or the microphone with Meeting in the room ticked. It has speakers, participants and subtitles.
  • Transcription: audio recorded by others, such as a podcast, an interview, a lecture or a link. It gets timestamps, participants and subtitles, and speaker labels if you tick Identify voices.

Start one from New

New has four tabs: Microphone, File, Link and System audio + mic.

  • Microphone records a note, or a meeting with Meeting in the room (several people on one mic, told apart by voice). Stop keeps it. Discard… sends what was transcribed to the trash.
  • File takes wav, mp3, m4a, aac, flac or ogg. You can drop it or choose it. Pick Note (the default) for a voice memo or Transcription for someone else's recording. The file is decoded as a stream, so an hour-long recording doesn't have to fit in memory.
  • Link is covered in its own post.

The Options card applies to every tab: language (Whisper only), cleanup level, default tags and category, and Save audio. The language and cleanup level apply to that run only and never change your dictation settings.

A long recording is split into segments at pauses. The pause detector is Silero voice-activity detection, a 0.9 MB model that downloads the first time a run needs it; if that download fails, a simpler energy detector takes over. Each segment is transcribed and cleaned while you keep talking, and the item is saved after every finished segment. If Sussurro or the computer crashes, the item is still there, marked Interrupted. A hotkey dictation during a long session goes first and doesn't wait for the backlog.

What's on disk

Each item is a folder: Documents/Sussurro/YYYY/MM/YYYY-MM-DD-<title>/.

  • transcript.md: the text, with a YAML frontmatter (type, title, date, duration, source, language, engine, tags, categories, participants).
  • document.md and other *.md: companion documents made by recipes, and answers you saved from Ask.
  • transcript.srt: subtitles, when created.
  • audio.wav (or one audio-<channel>.wav per channel on a meeting): only if you asked to save audio.
  • .sussurro/: the app's own files, such as timed segments, speakers and the log of external sends.

The frontmatter is the source of truth. Edit it or the text in any editor and Sussurro picks it up: the Library marks the item ✎ Edited outside, and your edit wins. Keys you add yourself are preserved. The folder can move: Settings → Archive → Archive folder (items already saved stay where they are). Sussurro warns you if the folder is inside iCloud Drive, OneDrive, Dropbox or Google Drive.

macOS asks once

On macOS the first-run setup creates the folder on purpose, so the “allow access to Documents” prompt appears then, while you're looking, and not in the middle of your first recording.

Find it again

The Library searches titles, text and tags, filters by type (Notes, Meetings, Transcriptions) and narrows with facets: Tag, Category, Participant and Date (today, this week, this month, this year, older, or a custom range). Choices within a facet are combined with OR, and different facets with AND. Badges flag items that are recording, interrupted, edited outside, have saved audio (♪) or were ↗ Sent externally to an LLM server off this machine. The index lives in the app's data folder and can be rebuilt from Settings → Archive.

Read, fix, export

Opening an item shows the Transcript, Document and Audio tabs, plus a side pane with Speakers (meetings and transcriptions), Ask and Export. You can edit the title, tags, categories and participants in place. Export offers .md, .txt, and for meetings and transcriptions .srt and .vtt, along with Copy text and Copy markdown. Subtitles are created only when you ask by default. Settings → Archive can switch that to Create .srt automatically on every save, and a transcript.srt you edited is never overwritten.

With saved audio, the Audio tab replays the item with the transcript highlighted as it plays. Play only plays one speaker's lines back to back from that speaker's own channel. Delete… and Delete audio… send files to the OS trash, not straight to oblivion.

Dictations stay out of the Library

Hotkey dictation works exactly as before and creates no Library items. Its history, with search, retention and export, is under Settings → Dictation history.
